6  Effect-size candidates (not significant)

Genes and pathways with a biologically sized Cre effect that do not reach padj < 0.05, laid out with every line of evidence so the choice of what to report can be made on the evidence.

6.1 Criteria and liver APOE biology

The main model finds no gene at padj < 0.05, which is expected with three batch-control GFP mice. This chapter collects every gene and pathway with a Cre-vs-GFP effect of at least 1.5-fold that does not reach significance. Each one comes with every line of evidence this dataset offers, so you can judge it.

Nothing here is an FDR-controlled discovery. The list is hypothesis-generating: candidates for a justified write-up and for qPCR. The criteria select the list; the evidence columns only describe it, and no gene is dropped for failing one.

Criteria (all parameters below):

Criterion Default Why
Effect size |log2FC| ≥ log2(1.5) in the main model the conventional minimum meaningful fold change; main model = batch-corrected, all controls
Expression baseMean ≥ 20 below this a 1.5-fold change is a handful of reads
Not significant padj ≥ 0.05 significant genes are already in chapter 4
Direction holds same sign in the 2025-10-only test and in every leave-one-GFP-out refit the sign cannot rest on one control mouse or on the run correction

Biological context. The switch replaces apoE4 with apoE2 on hepatocyte lipoproteins. The gene sets below follow from that biology:

  • receptor-mediated lipoprotein clearance (apoE2 binds LDLR poorly);
  • hepatocyte cholesterol sensing (SREBP2) and efflux;
  • VLDL assembly and triglyceride handling;
  • fatty-acid oxidation and synthesis;
  • bile acids;
  • ceramides (raised in these mice’s plasma lipidomics);
  • acute-phase / ER-stress responses.

Three sets were added after looking at this dataset: OXPHOS, the urea cycle (Ass1 / Asl) and interferon-γ response (Irgm / Gbp genes). They are kept as a separate family and cannot be presented as pre-specified.

Code 
# Effect-size candidates: genes / pathways whose Cre-vs-GFP effect is as large as a biologically
# meaningful change but that do not reach padj < PADJ_CUT. Every threshold is here so it can be
# changed; nothing below decides what is biologically important.
ES_LFC        <- log2(1.5)   # |batch-corrected log2FC| >= 1.5-fold (main model, unshrunk MLE)
ES_MIN_MEAN   <- 20          # baseMean floor: below this a 1.5-fold change is a few reads
ES_CONSISTENT <- TRUE        # also require the same sign in the 2025-10-only test and in every
                             # leave-one-GFP-out refit (direction cannot hinge on one control)
ES_GSEA_FDR   <- 0.25        # exploratory GSEA cut-off recommended by Subramanian et al. 2005
ES_NES        <- 1.5         # |NES| floor for genome-wide near-miss GO terms
ES_SHOW_OTHER <- 15          # candidates outside the APOE-liver sets shown in the figure (top |LFC|)

# apoE2 binds the LDL receptor poorly (remnant clearance, hepatocyte cholesterol delivery and so

# and inflammation (Mahley & Rall 2000; Mahley 2016). Plasma lipids, ceramides and triglycerides

6.2 Genes

Evidence per gene (columns ev_* in csv/deseq2/effect_size_candidates.csv):

  • p < 0.05, main model / p < 0.05, 2025-10 only: nominal (unadjusted) p values in the batch-corrected model and in the run-free 2025-10-only model.
  • Dose: within the Cre mice only, the slope of expression on each mouse’s liver E2 allelic fraction, in the same direction as the Cre effect (and p < 0.05). Batch cannot drive a within-group gradient, but the E2 range is narrow (about 0.87–0.96).
  • Germline E2 vs E4: same direction as EFAD E2/E2 vs E4/E4 liver. Those mice are run-clean, but they differ from the switch in colony, sex, age and lifelong exposure. Disagreement is informative, not disqualifying: the switch is acute and adult-onset.
  • Liver-specific: the brain effect is opposite in sign or less than half the liver effect.
  • Not a replicate false positive: the gene does not differ between the two runs of the same mouse.
  • Not tracking library quality: |r| < 0.6 with STAR uniquely-mapped % within the Cre mice.

Calibration. The brain column of the table below is the same filter applied where the switch should do nothing. The ratio of brain to liver counts is a rough guide to how many liver candidates could be noise. Brain has one fewer batch-control GFP mouse (B13 excluded), which makes brain somewhat noisier.

# dose-response per gene (summary in VALIDITY CHECKS): Cre mice only, ~ sex + E2 fraction
dose_gene_res <- function(tissue) {
  cm <- aav_meta(tissue) |> rownames_to_column("sample") |>
    dplyr::filter(treatment == "Cre", run == CRE_RUN) |>
    left_join(e2_by_mouse, by = "mouse_id") |> dplyr::filter(!is.na(e2_frac)) |>
    column_to_rownames("sample") |> mutate(e2_frac_c = as.numeric(scale(e2_frac)))
  DESeqDataSetFromMatrix(geneCounts[gene_qc[[tissue]]$keep, rownames(cm)], cm, ~ sex + e2_frac_c) |>
    norm_dds() |> DESeq(quiet = TRUE) |> results(name = "e2_frac_c")
}
res_col <- function(r, ids, col) as.data.frame(r)[ids, col]

# one row per gene: main effect + every line of evidence. `other` = the other tissue's main fit
# (liver-specific check for liver; for brain it is the liver fit, shown for symmetry).
es_table <- function(tissue) {
  f     <- fits$fit[[match(tissue, fits$tissue)]]
  other <- fits$fit[[match(setdiff(TISSUES, tissue), fits$tissue)]]$res
  germ  <- germline$res[[which(germline$tissue == tissue & germline$a == "E2" & germline$b == "E4")]]
  dose  <- dose_gene_res(tissue)
  loo   <- map(f$loo, \(l) l$res$log2FoldChange) |> purrr::reduce(cbind)
  if (is.null(dim(loo))) loo <- matrix(loo, ncol = 1)
  libq  <- cand_genes_all |> dplyr::filter(tissue == !!tissue) |>
    dplyr::select(ensemblID, r_with_lib_quality, replicate_fp)
  as_tibble(as.data.frame(f$res), rownames = "ensemblID") |>
    transmute(tissue = tissue, ensemblID, baseMean, log2FC = log2FoldChange, lfcSE, pvalue, padj,
              ci_lo = log2FC - 1.96 * lfcSE, ci_hi = log2FC + 1.96 * lfcSE,
              log2FC_shrunk = f$resLFC$log2FoldChange,
              loo_same_sign = rowSums(sign(loo) == sign(log2FC)) == ncol(loo),
              loo_min_abs_lfc = apply(abs(loo), 1, min),
              run_offset_log2 = f$offset[ensemblID]) |>
    mutate(log2FC_oct = res_col(f$within, ensemblID, "log2FoldChange"),
           p_oct      = res_col(f$within, ensemblID, "pvalue"),
           dose_lfc_per_sd = res_col(dose, ensemblID, "log2FoldChange"),
           p_dose     = res_col(dose, ensemblID, "pvalue"),
           log2FC_germline_E2vsE4 = res_col(germ, ensemblID, "log2FoldChange"),
           p_germline = res_col(germ, ensemblID, "pvalue"),
           log2FC_other_tissue = res_col(other, ensemblID, "log2FoldChange")) |>
    left_join(libq, by = "ensemblID") |>
    left_join(dplyr::select(id2name, ensemblID, Symbol), by = "ensemblID") |>
    left_join(dplyr::select(apoe_member, ensemblID, apoe_set = set, apoe_basis = basis, apoe_sets_all), by = "ensemblID") |>
    mutate(
      # the criteria (what puts a gene on the list)
      meets_effect = abs(log2FC) >= ES_LFC & baseMean >= ES_MIN_MEAN,
      not_sig      = is.na(padj) | padj >= PADJ_CUT,
      consistent   = sign(log2FC_oct) == sign(log2FC) & loo_same_sign,
      candidate    = meets_effect & not_sig & (consistent | !ES_CONSISTENT),
      # the evidence (reported, never used to drop a gene)
      ev_nominal_main     = pvalue < 0.05,      # NA = Cook's outlier, no p value
      ev_nominal_oct      = p_oct < 0.05,
      ev_dose_same_sign   = sign(dose_lfc_per_sd) == sign(log2FC),
      ev_dose_nominal     = ev_dose_same_sign & p_dose < 0.05,
      ev_germline_E2_like = sign(log2FC_germline_E2vsE4) == sign(log2FC),
      ev_germline_nominal = ev_germline_E2_like & p_germline < 0.05,
      # liver-specific: the switch acts in hepatocytes; a gene that moves as much in brain looks
      # like genetic background or a systemic / technical effect
      ev_tissue_specific  = is.na(log2FC_other_tissue) | sign(log2FC_other_tissue) != sign(log2FC) |
        abs(log2FC_other_tissue) < abs(log2FC) / 2,
      ev_not_replicate_fp = !replicate_fp %in% TRUE,
      ev_not_lib_quality  = is.na(r_with_lib_quality) | abs(r_with_lib_quality) < 0.6) |>
    relocate(tissue, ensemblID, Symbol, apoe_set, apoe_basis)
}

# How the list is built, step by step. Brain is the negative control: the AAV-TBG switch acts in
# hepatocytes, so the brain count is roughly what the same filter lets through without a switch.
es_funnel <- imap(es_by_tissue, \(d, t) {
  cand <- dplyr::filter(d, candidate)
  tibble(tissue = t,
         step = c("tested genes",
                  sprintf("|log2FC| >= %.2f and baseMean >= %d", ES_LFC, ES_MIN_MEAN),
                  sprintf("... and padj >= %.2f (not significant)", PADJ_CUT),
                  "... and same sign in 2025-10-only and every leave-one-out",
                  "... of which nominal p < 0.05 (main model)",
                  "... of which in an APOE-liver set"),
         n = c(sum(!is.na(d$pvalue)), sum(d$meets_effect, na.rm = TRUE),
               sum(d$meets_effect & d$not_sig, na.rm = TRUE), nrow(cand),
               sum(cand$ev_nominal_main, na.rm = TRUE), sum(!is.na(cand$apoe_set))))
}) |> bind_rows() |> pivot_wider(names_from = tissue, values_from = n)
write_csv(es_funnel, file.path(CSV_DIR, "deseq2", "effect_size_funnel.csv"))

6.3 Pathways

Pathways. Two complementary views:

  1. APOE-liver sets. GSEA of each set on the Wald statistic of every contrast that bears on the switch: main, 2025-10 only, within-Cre dose, germline E2 vs E4, and brain as the negative control. FDR is controlled within the small family (a priori / from this data), not across all of GO. Testing a few hypothesis-driven sets is the standard way to keep power, provided the sets are fixed before looking.
  2. Genome-wide GO near-misses. Terms with |NES| ≥ 1.5 and 0.05 ≤ FDR < 0.25 in the main liver GSEA, with leave-one-out and 2025-10-only direction. Subramanian et al. (2005) recommend FDR < 0.25 for exploratory GSEA.

Caveat: preranked GSEA permutes genes, not samples. It ignores correlation between genes, so its p values are optimistic for sets of co-regulated genes (Wu & Smyth 2012). Agreement across contrasts is a better guide than any single p value.

Code 
# 1. APOE-liver sets: GSEA on the Wald statistic (signed, scaled by uncertainty) of every contrast
#    that bears on the switch, so each set is read against the same lines of evidence as a gene.
#    FDR is controlled within each family (a priori / this data), not across all of GO: a small,
#    pre-specified family is the standard way to keep power for hypothesis-driven sets.
set_t2g <- apoe_sets |> dplyr::select(set, genes) |> unnest(genes) |> dplyr::rename(gene = genes)
stat_rank <- function(r) {
  s <- set_names(r$stat, rownames(r))
  sort(s[!is.na(s)], decreasing = TRUE)
}
gsea_sets <- function(r, contrast) {
  g <- clusterProfiler::GSEA(stat_rank(r), TERM2GENE = set_t2g, pvalueCutoff = 1, minGSSize = 5,
                             maxGSSize = 2000, eps = 0, seed = TRUE, verbose = FALSE) |>
    as.data.frame()
  tibble(set = g$ID, NES = g$NES, pvalue = g$pvalue, setSize = g$setSize,
         leading_edge = map_chr(str_split(g$core_enrichment, "/"),
                                \(x) paste(na.omit(id2name$Symbol[match(x, id2name$ensemblID)]), collapse = "/")),
         contrast = contrast)
}

# 2. genome-wide GO near-misses: |NES| >= ES_NES and PADJ_CUT <= padj < ES_GSEA_FDR in the main
#    liver GSEA (same ranking as PATHWAY ANALYSIS: shrunk log2FC), with leave-one-out and 2025-10-
#    only direction. GSEA's authors recommend FDR < 0.25 for exploratory, hypothesis-generating use.
near_miss <- map(c("BP", "MF", "CC"), \(o) {
  main <- gsea_all(lfc_table(liver_fit$res, liver_fit$resLFC$log2FoldChange), o)
  loo  <- imap(liver_fit$loo, \(l, k) gsea_all(lfc_table(l$res, l$lfc), o) |>
                 transmute(ID, NES_loo = NES, dropped = k)) |> bind_rows()
  w    <- gsea_all(lfc_table(liver_fit$within, liver_fit$within$log2FoldChange), o) |>
    transmute(ID, NES_within = NES)
  main |> dplyr::filter(abs(NES) >= ES_NES, p.adjust >= PADJ_CUT, p.adjust < ES_GSEA_FDR) |>
    transmute(ont = o, ID, Description, setSize, NES, pvalue, p.adjust,
              leading_edge = map_chr(str_split(core_enrichment, "/"), \(x)
                paste(na.omit(suppressMessages(mapIds(org.Mm.eg.db, x, "SYMBOL", "ENTREZID"))), collapse = "/"))) |>
    left_join(loo |> group_by(ID) |> summarise(n_loo = n(), loo_same_sign_n = list(sign(NES_loo)),
                                               .groups = "drop"), by = "ID") |>
    left_join(w, by = "ID") |>
    mutate(loo_same_sign = map2_lgl(loo_same_sign_n, NES, \(s, n) length(s) == length(liver_fit$loo) &&
                                      all(s == sign(n))),
           within_same_sign = sign(NES_within) == sign(NES)) |>
    dplyr::select(-loo_same_sign_n)
}) |> bind_rows() |> arrange(p.adjust)
write_csv(near_miss, file.path(CSV_DIR, "pathway", "liver_gseGO_near_miss.csv"))

6.4 Gene figures

Figures. On each gene row:

  • black dot: main-model log2FC, with its 95% CI;
  • pink ring: 2025-10 only;
  • blue triangle: germline E2 vs E4;
  • grey cross: brain;
  • dashed lines: the ±1.5-fold threshold;
  • *: a gene in a set chosen from this data.

The tiles on the right are the evidence columns.

fig_genes <- function(d, show_other = TRUE,
