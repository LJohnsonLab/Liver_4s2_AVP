2  The sequencing run and its correction

Cre mice were sequenced only in 2025-10; most GFP controls only in 2025-04. This chapter measures the run difference with the bridge mice, fits the main model with a batch term, and benchmarks the alternatives.

2.1 How the run effect was tested, and what was concluded

This section summarises the evidence in this chapter. The figures and tables follow below. Numbers are from the current sample set: B13, GLAD_164 and GLAD_150 excluded.

The design problem. All 10 Cre mice were sequenced in 2025-10. Most GFP controls were sequenced in 2025-04. Treatment and sequencing run are therefore almost completely confounded. Without a way to measure the run difference on its own, any Cre-vs-GFP difference could be the run. Three groups of samples make the run measurable without the treatment:

  • GFP mice sequenced in 2025-10 (liver A11, A12, A13; brain B11, B12): same treatment as the 2025-04 GFP mice, different run.
  • Bridge mice (SAD_326, MAD_271): the same animal’s tissue sequenced in both runs. Any difference between the two copies is technical.
  • SAD_532: a GFP mouse sequenced only in 2025-10, in the same run as the Cre mice.

Test 1. Do samples with the same treatment separate by run? GFP-only PCA, before correction, with sex regressed out (figure below, panels a–c).

  • Brain: yes. The 2025-10 GFP brains separate from the 2025-04 brains on PC1, and the two copies of bridge mouse MAD_271 land far apart. Across all AAV brains, run is the largest source of variation (R² 0.84 with PC1).
  • Liver: no. The 2025-10 GFP livers mix with the 2025-04 livers, and each bridge mouse’s two copies sit next to each other. Run appears only on PC3 (6% of variance, R² 0.71, overlapping with treatment by design). The largest liver axes are sex (PC1, R² 0.98) and mouse-to-mouse differences.

Test 2. Does a comparison with no treatment difference produce DEGs? 2025-10 GFP vs 2025-04 GFP, ~ sex + run, uncorrected. If the runs were equivalent this should give about zero.

  • Result: 657 DEGs in liver and 2,245 in brain (padj < 0.05).
  • 1,192 liver genes and 871 brain genes differ by more than 1.5-fold between runs.

Test 3. How different is the same mouse in two runs? Genes differing more than 2-fold between the two copies of a bridge mouse, compared with two different 2025-04 GFP mice.

Same mouse, two runs Different mice, same run (median)
Brain 200 (MAD_271) 106
Liver 146–181 556
  • Brain: the run changes a sample more than swapping in another mouse does.
  • Liver: mouse-to-mouse variation is larger than the run effect sample by sample. The run effect in liver is a consistent shift across many genes, which is why it still produces hundreds of DEGs in Test 2.

Test 4. Are the DEGs from the uncorrected Cre-vs-GFP comparison run artifacts? This is the benchmark below. Cre (2025-10) is compared with single-run 2025-04 GFP mice with no run correction, and each DEG’s direction is checked against the same-mouse run difference. If the DEGs were Cre biology, about 50% would match that direction by chance.

Uncorrected Cre vs GFP DEGs Same direction as the run difference
Liver 3,486 88%
Brain 6,799 97%

Test 5. Does a GFP mouse in the Cre run look like Cre? SAD_532 is GFP but was sequenced with the Cre mice. Its deviation from the 2025-04 GFP mean correlates with the uncorrected Cre-vs-GFP difference: r = 0.35 in liver and 0.77 in brain. A control mouse looks “Cre-like” only because of its run.

Test 6. Technical read fractions. Ribosomal-protein and mitochondrial read fractions per sample, by run and extraction batch (Technical differences, below). These show whether library composition differs between runs independently of treatment.

Conclusion. The two runs differ systematically in both tissues, but not equally.

  • Brain: the run effect is strong. It is the largest source of variation, it moves the same mouse further than swapping mice does, and it gives 2,245 DEGs between identically treated mice.
  • Liver: the run effect is real but smaller. It is not a major PCA axis and is smaller than the differences between mice. It is consistent across many genes, though: 657 DEGs between identically treated mice, and 88% of the uncorrected Cre-vs-GFP DEGs point in the run direction.

In both tissues, an uncorrected analysis would report the run as a Cre effect. Brain is the within-animal negative control: the switch is hepatocyte-specific, so brain should show essentially no Cre effect. An uncorrected brain Cre-vs-GFP “effect” of 6,799 DEGs, 97% in the run direction, is therefore direct evidence that the uncorrected signal is technical.

How it was corrected, and how the correction was checked.

  • Correction. A per-gene run offset was estimated from all GFP mice (~ sex + run) and built into the DESeq2 normalisation factors of the 2025-04 samples. The main model also carries the batch term, so the Cre-vs-GFP fold change is effectively anchored on the GFP mice sequenced in 2025-10.
  • Check 1, out of sample. Each 2025-10 GFP mouse in turn was left out of the offset estimate, and its run difference was retested after correction:
    • liver: 657 → 138, 150 and 479 DEGs (A11, A12, A13);
    • brain: 2,245 → 2 and 10 DEGs.
    • Correction removes nearly all of the run in brain and most of it in liver. A13 keeps the most, and it is also the outlying GFP liver in the within-sex PCA.
  • Check 2, within run. The corrected Cre-vs-GFP statistics were compared with a 2025-10-only Cre vs GFP comparison, which has no run confound.
  • Check 3, leave-one-out. Every result was refit with each 2025-10 GFP mouse removed.
  • Check 4, alternatives. RUVg, a technical covariate and cqn were benchmarked against the same held-out samples (benchmark below). None removed the run effect from the confounded design: run-aligned DEGs stayed at 74–97% wherever a method still produced many DEGs. That is why the main model uses the bridge-anchored offset plus batch term.
  • Floor. Comparing only the replicate copies gives a “false-positive” floor of 57 (liver) and 365 (brain) DEGs from the run alone (chapter 3).

After correction, Cre vs GFP gives 0 DEGs at padj < 0.05 in both tissues. The effect-size candidates in chapter 6 are filtered so that each keeps its direction in the 2025-10-only comparison and in every leave-one-GFP-out refit.

Limits.

  • The correction rests on few anchors: 3 liver and 2 brain GFP mice sequenced in 2025-10, and 2 liver and 1 brain bridge pairs.
  • Removing the run also removes power. Any true Cre effect that happens to point in the run direction is partly absorbed.
  • The 0-DEG result is therefore “no effect large enough to see past the correction”, not evidence of no effect.

2.4 DESeq2 model: Cre vs GFP with a batch term

Code 
# AAV samples of a tissue. dedup = TRUE (every model): ONE sample per mouse. MAD_271 and SAD_326
# were sequenced in both runs (the same animals, not separate controls), so their 2025-04 copy is
# dropped wherever a usable 2025-10 copy exists; the 2025-10 copy is kept because it anchors the
# batch term against the 2025-10 Cre mice. (SAD_326 brain: its 2025-10 sample B13 is excluded as
# a sample swap, so its 2025-04 brain R1_B1 is its only copy.) dedup = FALSE keeps both copies, for
# the analyses that use the replicates as replicates (bridge check, replicate floor, benchmark).
aav_meta <- function(tissue, dedup = TRUE) {
  m <- meta[meta$tissue == tissue & meta$arm == "AAV", , drop = FALSE]
  if (!dedup) return(m)
  dup <- m |> rownames_to_column("sample") |> group_by(mouse_id) |>
    dplyr::filter(n() > 1, run == GFP_RUN, any(run == CRE_RUN)) |> pull(sample)
  m[!rownames(m) %in% dup, , drop = FALSE]
}

# cqn normalisation factors (genes x samples, geometric mean 1 per gene) for a count matrix
cqn_nf <- function(cts) {
  gi <- match(rownames(cts), gene_gcl$GeneID)
  cq <- cqn::cqn(cts, x = gene_gcl$gc[gi], lengths = gene_gcl$length[gi],
                 sizeFactors = colSums(cts), verbose = FALSE)
  nf <- exp(cq$glm.offset)
  nf / exp(rowMeans(log(nf)))
}
# apply NORMALIZATION to a DESeqDataSet (DESeq() then uses these factors)
norm_dds <- function(dds) {
  if (NORMALIZATION == "cqn") {
    normalizationFactors(dds) <- cqn_nf(counts(dds))
    dds
  } else estimateSizeFactors(dds)
}
run_coef  <- function(dds) grep("^run_", resultsNames(dds), value = TRUE)

# Per-gene run offset (log2 2025-10 / 2025-04): FULL correction = unshrunk MLE run log2FC from
# all GFP samples of the tissue (~ sex + run). `drop` leaves 2025-10 GFP samples out (checks).
gfp_meta <- function(tissue, drop = character(), dedup = TRUE)
  aav_meta(tissue, dedup) |> rownames_to_column("sample") |>
  dplyr::filter(treatment == "GFP", !sample %in% drop) |> column_to_rownames("sample") |>
  mutate(run = factor(run, levels = c(GFP_RUN, CRE_RUN))) |> droplevels()

run_offset <- function(tissue, drop = character()) {
  genes <- gene_qc[[tissue]]$keep
  gm  <- gfp_meta(tissue, drop)
  dg  <- DESeqDataSetFromMatrix(geneCounts[genes, rownames(gm)], gm, ~ sex + run) |>
    norm_dds() |> DESeq(quiet = TRUE)
  off <- results(dg, name = run_coef(dg))$log2FoldChange
  set_names(replace_na(off, 0), genes)
}

# Normalization factors = size factors x run offset on the 2025-04 samples, rescaled so each
# gene's factors have geometric mean 1 (as DESeq2 expects).
offset_nf <- function(dds, offset) {
  base <- if (NORMALIZATION == "cqn") cqn_nf(counts(dds)) else
    matrix(sizeFactors(estimateSizeFactors(dds)), nrow(dds), ncol(dds), byrow = TRUE,
           dimnames = dimnames(dds))
  old <- colData(dds)$run == GFP_RUN
  base[, old] <- base[, old] * 2^(-offset[rownames(dds)])
  normalizationFactors(dds) <- base / exp(rowMeans(log(base)))
  dds
}

# Batch term for a set of samples: 2025-10 extraction batch (1 / 2, with 2025-04 = R1) if every
# 2025-10 extraction batch contains a GFP mouse, so treatment is estimated within batch;
# otherwise sequencing run only (e.g. brain after excluding B13: batch 1 has no GFP, and an
# extraction-batch term would leave Cre vs GFP resting on the single batch-2 Cre mouse).
design_for <- function(m) {
  new <- m[m$run == CRE_RUN, , drop = FALSE]
  ok  <- all(tapply(new$treatment == "GFP", droplevels(new[[BATCH]]), any))
  multi_run <- n_distinct(m$run) > 1
  if (ok && n_distinct(new[[BATCH]]) > 1) ~ sex + extraction_batch + treatment
  else if (multi_run) ~ sex + run + treatment
  else ~ sex + treatment
}

# PRIMARY: one GLM over 2025-10 Cre, 2025-10 GFP and 2025-04 GFP. The batch term removes the run
# difference completely (full correction) and propagates its uncertainty; the 2025-04 GFP
# contribute to the dispersion estimates. `drop` leaves samples out (leave-one-out).
fit_primary <- function(tissue, drop = character()) {
  m   <- aav_meta(tissue)
  m   <- m[!rownames(m) %in% drop, , drop = FALSE] |> droplevels()
  dds <- DESeqDataSetFromMatrix(geneCounts[gene_qc[[tissue]]$keep, rownames(m)], m,
                                design_for(m)) |> norm_dds() |> DESeq(quiet = TRUE)
  stopifnot(COEF %in% resultsNames(dds))
  dds
}

run_deseq <- function(tissue) {
  genes  <- gene_qc[[tissue]]$keep
  offset <- run_offset(tissue)        # used for the correction check and the figures only
  dds    <- fit_primary(tissue)
  res    <- results(dds, name = COEF, alpha = PADJ_CUT)
  resLFC <- lfcShrink(dds, coef = COEF, type = "apeglm", quiet = TRUE)

  # check 1: uncorrected run difference among GFP, then out-of-sample: each 2025-10 GFP sample
  # is left out of the offset estimate and compared with the corrected 2025-04 GFP
  gm     <- gfp_meta(tissue)
  before <- DESeqDataSetFromMatrix(geneCounts[genes, rownames(gm)], gm, ~ sex + run) |>
    norm_dds() |> DESeq(quiet = TRUE) |> results(alpha = PADJ_CUT)
  checks <- rownames(gm)[gm$run == CRE_RUN]
  oos <- map(set_names(checks), \(k) {
    om  <- gm[gm$run == GFP_RUN | rownames(gm) == k, , drop = FALSE] |> droplevels()
    d   <- DESeqDataSetFromMatrix(geneCounts[genes, rownames(om)], om, ~ run) |>
      offset_nf(run_offset(tissue, drop = k)) |> DESeq(quiet = TRUE)
    results(d, name = run_coef(d), alpha = PADJ_CUT)
  })

  # check 2: within-run Cre vs GFP (2025-10 only)
  wm <- aav_meta(tissue) |> dplyr::filter(run == CRE_RUN) |> droplevels()
  within <- DESeqDataSetFromMatrix(geneCounts[genes, rownames(wm)], wm, design_for(wm)) |>
    norm_dds() |> DESeq(quiet = TRUE) |> results(name = COEF, alpha = PADJ_CUT)

  # check 3: leave-one-out over the 2025-10 GFP (batch-control) mice
  loo <- if (length(checks) > 1)
    map(set_names(checks), \(k) {
      d <- fit_primary(tissue, drop = k)
      list(res = results(d, name = COEF, alpha = PADJ_CUT),
           lfc = lfcShrink(d, coef = COEF, type = "apeglm", quiet = TRUE)$log2FoldChange)
    }) else list()

  # display object: every AAV sample of the tissue, offset applied to 2025-04, for PCA/heatmaps
  am <- aav_meta(tissue) |> droplevels()
  dds_display <- DESeqDataSetFromMatrix(geneCounts[genes, rownames(am)], am, ~ 1) |>
    offset_nf(offset)

  list(dds = dds, res = res, resLFC = resLFC, offset = offset, checks = checks,
       design = paste(deparse(design(dds)), collapse = ""),
       check_before = before, check_oos = oos, within = within, loo = loo,
       dds_display = dds_display)
}

# Tutorial output table + run offset + the three checks + robust flag.
de_table <- function(fit) {
  norm <- counts(fit$dds, normalized = TRUE) |> as_tibble(rownames = "ensemblID")
  loo_ok <- if (length(fit$loo))
    map(fit$loo, \(l) !is.na(l$res$padj) & l$res$padj < PADJ_CUT &
                      sign(l$res$log2FoldChange) == sign(fit$res$log2FoldChange)) |>
      purrr::reduce(`&`) else rep(TRUE, nrow(fit$res))
  as_tibble(as.data.frame(fit$res), rownames = "ensemblID") |>
    mutate(log2FoldChange_shrunk  = fit$resLFC$log2FoldChange,
           run_offset_log2        = fit$offset[ensemblID],
           log2FoldChange_withinrun = fit$within$log2FoldChange,
           padj_withinrun         = fit$within$padj,
           loo_sig                = loo_ok,
           direction_agrees       = sign(log2FoldChange) == sign(log2FoldChange_withinrun),
           robust = !is.na(padj) & padj < PADJ_CUT & loo_sig & direction_agrees %in% TRUE) |>
    left_join(dplyr::select(id2name, ensemblID, Symbol, biotype), by = "ensemblID") |>
    relocate(ensemblID, Symbol, biotype) |>
    left_join(norm, by = "ensemblID") |>
    arrange(padj)
}

2.7 Batch-correction benchmark

Question: with Cre (2025-10 run) and GFP (2025-04 run) sequenced in different runs, which correction removes the run effect while keeping Cre biology? Each method is fitted on a fully run-confounded set, and graded only on samples it never saw.

  • Model set: 2025-10 Cre (10) vs 2025-04 GFP from mice sequenced only once (6; GLAD_164 and GLAD_150 are excluded as germline E2 carriers, and the double-run mice SAD_326 and MAD_271 are left out entirely). The 2025-04 Cre samples are not used: they were different, misgenotyped mice.
  • Held-out validation: the double-run mice (same animal in both runs = pure run effect), SAD_532 (2025-10 GFP, single run), and the 2025-10-only Cre vs GFP comparison (no run confound).

Methods:

  • none: ~ sex + treatment (the run-confounded comparison).
  • RUVg_HK_k: RUVg (Risso et al. 2014) with a priori negative controls = mouse orthologues of the Eisenberg & Levanon (2013) human housekeeping genes; k = 1-3 factors added to the model.
  • tech_cov: per-sample technical covariate (STAR uniquely-mapped %), slope estimated within group because treatment is in the model.
  • cqn: conditional quantile normalisation of gene GC content and length (Hansen et al. 2012) as DESeq2 normalisation factors.
  • cqn_RUVg_HK_1: both.
  • bridge_offset: the full run correction estimated from the double-run mice (reference only; it uses the held-out samples, so its bridge score is circular).

Scores (per tissue):

  • bridge_genes_2fold: genes differing > 2-fold between the two copies of the same mouse after correction (lower = more batch removed).
  • SAD532_cre_likeness: correlation of SAD_532’s deviation from the 2025-04 GFP mean with the Cre-vs-GFP difference. SAD_532 is a GFP mouse in the Cre run, so > 0 means run effect left over.
  • run_aligned_pct: % of the method’s DEGs whose direction matches the same-mouse run difference (50% = chance; 90%+ = DEGs are run).
  • r_with_within_run: Spearman of the method’s Cre-vs-GFP statistic with the 2025-10-only statistic (unconfounded; higher = more of the true Cre signal kept). Both use the same Cre mice, which raises every method’s value equally.

bench_tissue <- function(tissue) {
  genes <- gene_qc[[tissue]]$keep
  aav   <- aav_meta(tissue, dedup = FALSE) |> rownames_to_column("sample")
  double_mice <- aav |> dplyr::filter(treatment == "GFP") |> group_by(mouse_id) |>
    dplyr::filter(n_distinct(run) == 2) |> pull(mouse_id) |> unique()
  # SAD_326's 2025-10 brain (B13) is excluded, so in brain it no longer has two runs; it is still a
  # double-run mouse, so its 2025-04 copy stays out of the model set
  double_mice <- union(double_mice, c("SAD_326", "MAD_271"))
  model <- aav |> dplyr::filter(!mouse_id %in% double_mice,
                                (treatment == "Cre" & run == CRE_RUN) | (treatment == "GFP" & run == GFP_RUN))
  bridges <- aav |> dplyr::filter(mouse_id %in% double_mice) |> group_by(mouse_id) |>
    dplyr::filter(n_distinct(run) == 2) |> ungroup()
  s532  <- aav |> dplyr::filter(treatment == "GFP", run == CRE_RUN, !mouse_id %in% double_mice) |> pull(sample)
  all_s <- unique(c(model$sample, bridges$sample, s532))
  am    <- aav_meta(tissue, dedup = FALSE)[all_s, , drop = FALSE] |> droplevels()
  am$uniq <- as.numeric(scale(star_map_bm$Uniquely_mapped_reads_pct[match(all_s, star_map_bm$sample)]))
  cts   <- geneCounts[genes, all_s]
  mm    <- am[model$sample, , drop = FALSE] |> droplevels()
  # common normalised log scale for all samples
  sf    <- estimateSizeFactorsForMatrix(cts)
  Y     <- log2(t(t(cts) / sf) + 1)

  # same-mouse run difference (2025-10 minus 2025-04), averaged over bridge mice
  run_diff <- bridges |> split(~ mouse_id) |>
    map(\(b) Y[, b$sample[b$run == CRE_RUN]] - Y[, b$sample[b$run == GFP_RUN]]) |>
    purrr::reduce(`+`) / n_distinct(bridges$mouse_id)

  # nuisance-corrected log values for ALL samples: coefficients from the model set (treatment and
  # sex protected), applied to every sample
  regress_out <- function(Z) {
    X  <- model.matrix(~ sex + treatment, mm)
    D  <- cbind(X, Z[model$sample, , drop = FALSE])
    B  <- limma::lmFit(Y[, model$sample], D)$coefficients[, colnames(Z), drop = FALSE]
    Y - B %*% t(Z[colnames(Y), , drop = FALSE])
  }
  deseq <- function(m, des, nf = NULL) {
    d <- DESeqDataSetFromMatrix(cts[, rownames(m)], m, des)
    if (!is.null(nf)) normalizationFactors(d) <- nf[, rownames(m)] / exp(rowMeans(log(nf[, rownames(m)])))
    results(DESeq(d, quiet = TRUE), name = COEF, alpha = PADJ_CUT)
  }
  ruv_W <- function(k, x = cts) {
    ctl <- intersect(hk_mouse, rownames(x))
    W <- RUVSeq::RUVg(x, cIdx = ctl, k = k, isLog = FALSE)$W
    rownames(W) <- colnames(x); colnames(W) <- paste0("W_", seq_len(k)); W
  }
  methods <- list()
  methods$none <- list(res = deseq(mm, ~ sex + treatment), Yc = Y)
  for_k <- map(1:3, \(k) {
    W  <- ruv_W(k); mw <- cbind(mm, W[rownames(mm), , drop = FALSE])
    list(res = deseq(mw, reformulate(c(colnames(W), "sex", "treatment"))), Yc = regress_out(W))
  }) |> set_names(paste0("RUVg_HK_", 1:3))
  methods <- c(methods, for_k)
  Zt <- matrix(am$uniq, dimnames = list(rownames(am), "uniq"))
  methods$tech_cov <- list(res = deseq(mm |> mutate(uniq = am[rownames(mm), "uniq"]), ~ uniq + sex + treatment),
                           Yc = regress_out(Zt))
  if (file.exists(gcl_file)) {
    gcl <- read_tsv(gcl_file, show_col_types = FALSE)
    gi  <- match(genes, gcl$GeneID)
    cq  <- cqn::cqn(cts, x = gcl$gc[gi], lengths = gcl$length[gi], sizeFactors = colSums(cts),
                    verbose = FALSE)
    nf  <- exp(cq$glm.offset)
    Ycq <- cq$y + cq$offset
    methods$cqn <- list(res = deseq(mm, ~ sex + treatment, nf = nf), Yc = Ycq)
    W1  <- ruv_W(1)
    mw  <- cbind(mm, W1[rownames(mm), , drop = FALSE])
    Y_bak <- Y; Y <- Ycq; Yc <- regress_out(W1); Y <- Y_bak
    methods$cqn_RUVg_HK_1 <- list(res = deseq(mw, ~ W_1 + sex + treatment, nf = nf), Yc = Yc)
  }
  # reference: full run offset from the double-run mice (circular on the bridge score)
  off <- rowMeans(as.matrix(run_diff))
  nf_b <- matrix(1, nrow(cts), ncol(cts), dimnames = dimnames(cts))
  nf_b[, am$run == GFP_RUN] <- 2^(-off)
  nf_b <- t(t(nf_b) * sf)
  Yb <- Y; Yb[, am$run == GFP_RUN] <- Yb[, am$run == GFP_RUN] + off
  methods$bridge_offset <- list(res = deseq(mm, ~ sex + treatment, nf = nf_b), Yc = Yb)

  within <- fits$fit[[match(tissue, fits$tissue)]]$within
  gfp_m  <- model$sample[model$treatment == "GFP"]; cre_m <- model$sample[model$treatment == "Cre"]
  imap(methods, \(m, nm) {
    r   <- m$res; sig <- which(r$padj < PADJ_CUT)
    Yc  <- m$Yc
    pair_genes <- bridges |> split(~ mouse_id) |>
      map_dbl(\(b) sum(abs(Yc[, b$sample[b$run == CRE_RUN]] - Yc[, b$sample[b$run == GFP_RUN]]) > 1))
    cre_sig <- rowMeans(Yc[, cre_m]) - rowMeans(Yc[, gfp_m])
    s532_dev <- if (length(s532)) Yc[, s532[1]] - rowMeans(Yc[, gfp_m]) else NA
    both <- intersect(rownames(r)[!is.na(r$stat)], rownames(within)[!is.na(within$stat)])
    tibble(tissue = tissue, method = nm, DEGs = length(sig),
           run_aligned_pct = if (length(sig)) 100 * mean(sign(r$log2FoldChange[sig]) == sign(run_diff[sig])) else NA_real_,
           bridge_genes_2fold = mean(pair_genes),
